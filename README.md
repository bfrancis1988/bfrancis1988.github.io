# bfrancis1988.github.io

Source for the Francis Designs developer hub, published at
<https://bfrancis1988.github.io>.

Francis Designs is a small independent game studio. The site currently
showcases Ember Crown, a fantasy card battler for mobile.

## Structure

- `index.html` — single-page hub
- `style.css` — styling (dark fantasy aesthetic, no JS, no frameworks)
- `app-ads.txt` — AdMob verification file (root path required)
- `images/` — project screenshots

## app-ads.txt

The `app-ads.txt` file at the root of this site is used by AdMob to
verify ad inventory ownership. Its contents must be kept in sync with
the line provided by AdMob (AdMob → Apps → app-ads.txt). If the file
is missing or incorrect, ad serving may be restricted.
